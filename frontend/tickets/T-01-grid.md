# T-01 プロジェクト初期化とグリッド描画

## 目的

10×8 の方眼を画面に描く。まだ何も置けなくてよい。以降のチケットが乗る土台を作る。

## 完了条件

- [×] `frontend/` に Vite + React + TypeScript のプロジェクトが作られている
- [×] Tailwind CSS が動作している
- [×] `src/types/map.ts` に `CLAUDE.md` の型定義がそのまま置かれている
- [×] 10 列 × 8 行の方眼が画面中央に表示される
- [×] セルサイズが定数として 1 箇所に定義されている
- [×] `npm run build` が型エラーなく通る

## 実装メモ

セルサイズは以降すべての座標計算の基準になる。`const CELL_SIZE = 48` のように 1 箇所で定義し、直接数値を書かない。

方眼は背景でしかない。**セルごとに種別を持つ配列を作ってはいけない。** 保持するデータは棚などのオブジェクト配列だけになる（T-02 以降）。

- オブジェクトの配置
- API 通信
- 見た目の作り込み
