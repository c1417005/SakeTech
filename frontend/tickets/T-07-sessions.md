# T-07 来店者のポーリング表示

## 目的

作ったマップの上に、実際の来店者を表示する。

## 完了条件

- [ ] `GET /sessions` を 10 秒間隔でポーリングする
- [ ] 来店者がマップ上にマーカーとして表示される
- [ ] `state` に応じて見た目が変わる（moving / viewing / hesitating）
- [ ] `hesitating` のマーカーが目立つ
- [ ] 状態は色だけでなく**文字ラベルでも**区別できる
- [ ] マーカーの移動が CSS トランジションで補間される
- [ ] 来店者が 0 人のとき「現在、来店者はいません」と明示される
- [ ] 画面を離れてもタイマーが多重起動しない

## 実装メモ

**座標は整数、更新は 10 秒間隔なので、素直に描くと点が瞬間移動する。** 店主から見ると何が起きたか分からない。数百ミリ秒の CSS トランジションを最初から入れる。

このアプリはレジ横で営業時間中つけっぱなしにされる。ポーリングのタイマーとイベントリスナの後始末を確実に行う。

`shelf_id` はバックエンドの判定結果をそのまま使う。フロントで隣接判定を再計算しない。

## スコープ外

- 客カード（見た目タグ・推定タグ）の表示
- 音やトーストによる通知（マップ上の変化のみとする方針）
