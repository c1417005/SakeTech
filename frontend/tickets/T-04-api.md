# T-04 API 層とモックモード

## 目的

通信を 1 箇所に閉じ込め、バックエンドが未完成でも全機能が動く状態にする。

## 完了条件

- [ ] `src/api/` に `getMap` / `saveMap` / `getSessions` が定義されている
- [ ] `VITE_USE_MOCK=true` のときモック実装に切り替わる
- [ ] モック実装は実 API と同じ型を返す
- [ ] コンポーネント側がモックかどうかを知らずに動く
- [ ] `GET /map` の結果でマップを復元でき、編集を続けられる
- [ ] マップが未登録の場合、空の状態で開始できる

## 実装メモ

**モックモードは任意機能ではない。** ハッカソン当日のデモは画面内シミュレーションで行うため、これが本番経路になる。実 API が落ちてもデモが継続できる保険でもある。

モックのマップデータは、背中合わせの棚を含むものにしておくと facing の確認になる。
