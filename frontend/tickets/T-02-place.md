# T-02 オブジェクトのパレットとドラッグ配置

## 目的

棚・レジ・出入口をドラッグで方眼に置けるようにする。

## 完了条件

- [ ] パレットから 1×2 / 1×3 / 1×4 の棚、レジ、出入口を選べる
- [ ] ドラッグで方眼に配置でき、マス目にスナップする
- [ ] 配置済みのオブジェクトをドラッグで移動できる
- [ ] 他のオブジェクトと重なる位置には置けない
- [ ] グリッドの外にはみ出す位置には置けない
- [ ] 置けない位置ではドラッグ中に視覚的に分かる
- [ ] 状態が `MapObject[]` の 1 配列だけで管理されている

## 実装メモ

Pointer Events を使う。HTML5 Drag and Drop API は使わない。

```ts
const col = Math.floor((e.clientX - rect.left) / CELL_SIZE);
```

重なり判定は、各オブジェクトの占有セル集合を求めて交差を見るだけでよい。棚が 1×N に限定されているので複雑な形状は存在しない。

棚の初期 `facing` は `north` でよい（向きの変更は T-03）。
