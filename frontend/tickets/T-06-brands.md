# T-06 棚への銘柄の紐づけ

## 目的

棚に置いてある銘柄を登録できるようにする。

## 完了条件

- [ ] 棚を選択すると銘柄を検索・追加できる
- [ ] 検索対象は**石川県の銘柄に限定**されている
- [ ] 追加した銘柄が `brand_ids` に反映される
- [ ] 銘柄を棚から外せる
- [ ] さけのわデータの**帰属表示**が画面内にある
- [ ] フレーバー情報がない銘柄でも、銘柄名だけで追加できる

## 実装メモ

銘柄は独立したオブジェクトではなく、**棚の属性**として持つ。`objects` 配列の構造を変えない。

さけのわ API は全件一括で返る形式のため、**フロントから直接叩かない。** 銘柄一覧はバックエンド経由で取得する。エンドポイントが未定であれば、モック実装で進めて TODO を残す。

帰属表示は利用規約上の必須要件。省略しない。

## スコープ外

- 銘柄ごとの在庫数
- 味の特徴の表示（棚詳細パネルは別チケット）
