# T-05 保存（自動＋ボタン）とステータス分岐

## 目的

編集内容がサーバーに保存され、その結果が店主に分かる言葉で伝わるようにする。

## 完了条件

- [ ] 操作後 2 秒ほど操作がなければ自動で POST される
- [ ] 保存ボタンで即時 POST できる
- [ ] 「保存済み / 保存中 / 未保存」が画面の隅に常時表示される
- [ ] 自動保存のたびにトーストを出していない
- [ ] 下記のステータス分岐が実装されている
- [ ] 失敗しても編集内容が失われない

## ステータス別の表示

| ステータス | 表示 |
|---|---|
| 200 / 201 | 「保存済み」＋保存時刻 |
| 400 | 「マップの内容に問題があります」 |
| 409 | 「他の端末で更新されています」 |
| 403 / 401 | 「保存の権限がありません」 |
| 5xx / タイムアウト | 「保存できませんでした」＋次の自動保存で再試行 |

## 実装メモ

送信するのは `MapData` をそのまま。フロントで組み立て直す処理を書かない。

**ステータスコードの数字を画面に出さない。** 利用者は IT に不慣れな店主であり、数字は何の情報にもならない。

## 確認が必要な点

403 が実際にどういう場合に返るのか、バックエンド担当と未合意。**この分岐が不要になる可能性がある。** 実装は残しつつ、TODO コメントで未確認であることを明示する。
